# Backup Figures

Store exported static screenshots and figures here before the workshop release. These files let facilitators continue the session if the venue network is weak or participant devices cannot load the interactive app.

Suggested naming:

- `01-pooled-vs-stratified.png`
- `02-within-vs-meta.png`
- `03-global-vs-local-ancestry.png`
- `04-complexity-power.png`
- `05-regularization-heterogeneity.png`
- `06-scalability-equity.png`

Run `npm run export:figures` after regenerating scenario data. The export starts the
static app locally and captures each complete module at its default control state.
