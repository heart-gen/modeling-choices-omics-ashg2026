# Archive

Working documents from building the platform for the ASHG 2026 workshop (Montréal,
October 20, 2026). They were written for the workshop's co-organiser, so they state
problems plainly, and they are
kept because they record *why* the platform looks the way it does: which claims in the
workshop abstract were built and which were cut, what the reviews found, and how each
finding was fixed.

They describe the repository as it was at the time. They are not current instructions —
for those, see the top-level `README.md`, `CONTRIBUTING.md`, and `deploy/README.md`.

- `review-2026-07.md` — gap analysis of the platform against the workshop abstract, and
  the work plan that followed from it, through the first deployment.
- `review-2026-10-deck.md` — the platform checked against the organiser's slide deck six
  days before the session, and the organiser's walkthroughs of the live build.

The deployment's AWS account, distribution, and URL have been removed; the session ran on a
CloudFront distribution in a Northwestern-owned account.
