# Workshop slides

The deck presented at the ASHG 2026 workshop **Modeling Choices in Omics: Implications for
Health Disparities in Human Genetics** (Montréal, October 20, 2026).

- [`ASHG2026-modeling-choices.pdf`](./ASHG2026-modeling-choices.pdf) — opens in the browser.
- [`ASHG2026-modeling-choices.pptx`](./ASHG2026-modeling-choices.pptx) — the editable deck,
  with speaker notes for every module slide.

## What differs from the session

One slide. The join slide (slide 4) gave the room a short link and QR code for the session's
own deployment, which no longer serves the workshop. In this copy both point to the
open-access site, <https://heart-gen.github.io/modeling-choices-omics-ashg2026/>. Every other
slide is as presented.

The PDF was exported with LibreOffice. It substitutes metric-compatible fonts for Arial and
Palatino, and sets the bullet text on slide 37 slightly larger than PowerPoint does.

## How the deck was made

The platform slides (join, agenda, each module's question, answer and reveal charts, and the
synthesis) were generated from the scenario bundles and from charts captured off the running
app. See [`workshop/slides/`](../workshop/slides/) for the build. The literature slides
between modules were added by hand.
